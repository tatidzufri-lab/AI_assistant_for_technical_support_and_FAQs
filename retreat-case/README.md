# AI-ассистент для техподдержки и ответов на вопросы

## О проекте

Чат-ассистент, встроенный в лендинг женского ретрита «Познай себя». Посетитель сайта нажимает на иконку чата в правом нижнем углу, задаёт вопрос на естественном языке и сразу получает ответ — без ожидания оператора и без поиска по сайту.

## Задача

Организатор ретрита получает одни и те же вопросы: о программе, условиях проживания, питании, стоимости и правилах участия. Часть вопросов приходит от сотрудников, которым нужны шаблоны служебных писем. Ручная обработка отнимает время и не масштабируется.

Нужно автоматизировать ответы на типовые вопросы так, чтобы посетитель получал точную, дружелюбную информацию мгновенно, а нестандартные запросы корректно отклонялись.

## Решение

На платформе OpenAI собран многошаговый workflow — цепочка специализированных агентов, каждый из которых отвечает за свою тему. Workflow встроен в лендинг через плавающий чат-виджет: бэкенд создаёт безопасную сессию, а виджет отображает диалог в iframe прямо на странице.

## Как это работает

1. Посетитель открывает лендинг и нажимает кнопку чата. Виджет запрашивает у бэкенда временный ключ сессии.
2. Бэкенд обращается к OpenAI API, создаёт сессию ChatKit и возвращает ключ браузеру. Секретный API-ключ при этом остаётся на сервере и никогда не попадает в клиентский код.
3. Вопрос пользователя проходит через защитный узел (Jailbreak guardrail), который фильтрует попытки манипуляции и нежелательный контент.
4. Классификатор определяет тему вопроса и направляет его к нужному агенту:
   - **FAQ Agent** — отвечает на вопросы клиентов о программе, проживании, питании, стоимости и возвратах.
   - **Docs Agent** — помогает клиентам разобраться в правилах, условиях оплаты и возврата.
   - **Templates Agent** — выдаёт сотрудникам шаблоны служебной переписки (доступ по коду).
   - **Welcome Message** — приветствует нового пользователя и кратко объясняет возможности ассистента.
   - **Off Topic Handler** — вежливо отклоняет вопросы, не относящиеся к ретриту.
5. Ответ агента возвращается в виджет и отображается в ленте диалога.

## Результат

Посетитель получает мгновенный ответ по теме ретрита в формате живого диалога. Сотрудники могут запрашивать шаблоны переписки. Нерелевантные и манипулятивные запросы отклоняются корректно. Организатор экономит время на рутинных ответах и может сосредоточиться на содержании программы.

## Стек технологий

| Технология | Для чего используется |
|---|---|
| **OpenAI Agent Builder** | Визуальный редактор, в котором собран многошаговый workflow: классификация вопросов, маршрутизация по темам и генерация ответов специализированными агентами. |
| **OpenAI ChatKit** | Встраиваемый чат-компонент от OpenAI. Подключается к workflow через сессию и отображает диалог в iframe на лендинге. |
| **OpenAI API (Responses API)** | Серверный интерфейс для создания сессий ChatKit. Бэкенд отправляет запрос с идентификатором workflow и получает временный ключ для браузера. |
| **FastAPI** | Python-фреймворк для бэкенда. Обрабатывает запросы на создание сессии, управляет CORS и cookie. |
| **Uvicorn** | ASGI-сервер, на котором запускается FastAPI-приложение. |
| **httpx** | HTTP-клиент для асинхронных запросов из бэкенда к OpenAI API. |
| **python-dotenv** | Загружает переменные окружения (API-ключ, ID workflow) из файла, чтобы секреты не попадали в код. |
| **HTML / CSS / JavaScript** | Лендинг ретрита: адаптивная вёрстка, типографика (Playfair Display + Nunito), плавающий виджет чата. |
| **Google Fonts** | Подключение шрифтов Playfair Display и Nunito для оформления лендинга. |
